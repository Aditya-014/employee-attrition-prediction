# Employee Attrition Prediction System

## Overview

This project is a Machine Learning-based Employee Attrition Prediction System developed during the AIML Summer Internship 2026 at IIHMF, Motilal Nehru National Institute of Technology (MNNIT), Prayagraj.

The system predicts whether an employee is likely to leave an organization based on employee-related information using the IBM HR Analytics Employee Attrition Dataset.

---

## Features

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Logistic Regression
- Random Forest
- XGBoost
- Model Comparison
- Streamlit Web Application
- Real-time Employee Attrition Prediction
